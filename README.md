# OPE Osakidetza — práctica de preguntas

Sitio estático generado automáticamente. No editar a mano.

- `index.html`: aplicación autocontenida (700 preguntas).
- `bibliografia/comun/`: leyes, decretos y planes (lectores con líneas + PDF).
- `bibliografia/fem/`: Manual de vacunaciones y guías GESIDA (lectores + PDF).

La guía ESC 2023 de endocarditis no se aloja: se enlaza a la web oficial de la ESC.

Para actualizar, regenerar con `node tools/publish.js` y volver a subir el contenido de `dist/`.
